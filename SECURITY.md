# Security policy

Report vulnerabilities to security@aerentmarketplace.com with a description and reproduction steps.

In scope: `contracts/AerentMarketplace.sol` as deployed, this website, the indexer API.
Out of scope: third-party wallets, RPC providers, Chainlink, Robinhood Chain itself.

Please do not exploit a finding beyond what is needed to prove it, do not touch funds that are not yours, and allow reasonable time for a fix before disclosure. Rewards for valid reports will be published with the bug bounty programme before significant TVL is accepted.
